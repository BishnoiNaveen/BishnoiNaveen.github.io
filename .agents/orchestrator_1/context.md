# Project Context: Naveen Bishnoi Portfolio Redesign

## Core Directives & Guidelines
- **User Intent**: Complete redesign of Naveen Bishnoi Portfolio with Apple-style fluid UI, deep Workflows & Hermes data integration, and high performance.
- **Technology Stack**: Astro, React, TypeScript, Tailwind CSS, Framer Motion (spring physics: damping/response).
- **Quality Gates**:
  - No dummy/facade implementations.
  - Zero hardcoding of test assertions.
  - Full automated build and test passing.
  - Forensic audit clean.
  - Lighthouse performance score >= 90.

## Survey Scope
- Explorer 1: Inspect Astro configuration, dependencies, existing code, package.json, directory structure.
- Explorer 2: Apple Fluid UI design tokens, spring physics specifications (WWDC 2018), Framer Motion integration in Astro islands.
- Explorer 3: Workflows and Hermes data schema, content requirements, local data modeling.
